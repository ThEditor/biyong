# @biyong/mobile

## Purpose
The primary client for Biyong. Built on React Native and Expo with Gluestack UI design system and local SQLite persistence.

## Ownership
Mobile Application Engineering.

## Architecture
- 100% offline-capable personal ledger.
- Local SQLite database.
- Centralized theme tokens supporting 6 accent presets and Light/Dark/System.

## Verification Commands

pnpm --filter @biyong/mobile typecheck
